## About the Project
Online Book Borrowing Platform is a digital library and book borrowing management system. It replaces manual, paper-based library tracking with a dynamic, state-driven, automated workflow.

---

## Project Overview
The primary goal of this project is to create an efficient, user-friendly system that lets students/users explore available books by category, track quantities, and seamlessly borrow or return books — all while keeping their profile secure.

## Installation & Setup
1. Clone the repo and install dependencies:
```bash
git clone https://github.com/rupa3670/online-book-borrowing-platform.git
cd online-book-borrowing-platform
npm install
```
2. Set up environment variables by creating a `.env` file in the root directory:
```env
DATABASE_URL=your_database_url
BETTER_AUTH_SECRET=your_auth_secret
```
3. Run the application:
```bash
npm run dev
```
Open http://localhost:3000 to view it in the browser.
