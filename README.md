# Online Book Borrowing Platform
<br>
A modern and secure web application designed to manage and streamline the process of borrowing and managing books online.

<br>
## Purpose of the Project:<br>
The primary goal of this project is to create an efficient, user-friendly Digital <br>Library and Book Borrowing Management System. It allows students/users to explore <br>available books by category, track quantities, and seamlessly borrow or return <br>books while keeping their user profile secure. <br>It replaces manual library tracking with a dynamic,<br> state-driven automated workflow.
<br>
<br>
## Live Link:https://online-book-borrowing-platform-six.vercel.app/all-books
<br>
<br>
## Key Features

* Secure Authentication: Implemented robust user sign-up and login<br> functionality using `BetterAuth`, including secure Email/Password <br>registration and **Google Social Login** integration.<br>
*   Protected Profile Management:** Users have a dedicated dashboard to view their <br>profile details and dynamically update their display name and profile <br>image URL with full data synchronization.
*   Dynamic Book Sliders:** Integrated `SwiperJS` to create modern, touch-friendly,<br> and interactive book carousels on the homepage for an engaging user experience.<br>
*  Dynamic Book Showcase:** Features a clean, responsive UI displaying books across<br> multiple categories (Story, Tech, Science) with live quantity tracking <br>(`available_quantity`).
*  Controlled Registration Flow:** Custom registration architecture that safely signs<br> up users and automatically redirects them to the dedicated Login Page to <br>prevent unauthorized automatic access.<br>
*   Fully Responsive & Beautiful UI:** Built using `Tailwind CSS` and `DaisyUI` for a <br>modern, sleek, and mobile-friendly terminal-inspired visual aesthetic.<br>
*  Robust Form Validation & Notifications:** Safe form handling using `React Hook Form` and<br> instant feedback alerts via `React-Toastify` for all successful or failed operations.<br>
